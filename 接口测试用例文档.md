# 接口测试用例文档

## URL：https://dummyjson.com



## 模块一：用户登录接口（POST /auth/login）

| 编号 | 用例名称         | 模块 | 优先级 | 请求方法 | URL                    | 请求头                        | 请求体（请求数据）                   | 预期结果                                        |
| ---- | ---------------- | ---- | ------ | -------- | ---------------------- | ----------------------------- | ------------------------------------ | ----------------------------------------------- |
| TC01 | 正常登录         | 登录 | P0     | POST     | {协议+域名}/auth/login | Content-Type:application/json | username=emilys, password=emilyspass | 状态码200，返回accessToken和refreshToken        |
| TC02 | 密码错误         | 登录 | P1     | POST     | {协议+域名}/auth/login | Content-Type:application/json | username=emilys, password=错误密码   | 状态码400，提示"Invalid credentials"            |
| TC03 | 用户名为空       | 登录 | P1     | POST     | {协议+域名}/auth/login | Content-Type:application/json | username="", password=emilyspass     | 状态码400，提示"Username and password required" |
| TC04 | 密码为空         | 登录 | P1     | POST     | {协议+域名}/auth/login | Content-Type:application/json | username=emilys, password=""         | 状态码400，提示"Username and password required" |
| TC05 | 账号密码都不存在 | 登录 | P1     | POST     | {协议+域名}/auth/login | Content-Type:application/json | username=aaaaaaa, password=aaaaaaa   | 状态码400，提示"Invalid credentials"            |
| TC06 | 密码字段不存在   | 登录 | P1     | POST     | {协议+域名}/auth/login | Content-Type:application/json | username=emilys                      | 状态码400，提示"Username and password required" |



## 模块二：商品接口（/products）

| 编号 | 测试点           | 接口                     | 方法   | 输入                 | 预期结果                                         |
| ---- | ---------------- | ------------------------ | ------ | -------------------- | ------------------------------------------------ |
| TC01 | 查询单个商品     | {协议+域名}/products/1   | GET    | id=1                 | 状态码200，c                                     |
| TC02 | 查询不存在商品id | {协议+域名}/products/666 | GET    | id=666               | 状态码404，提示“Product with id '666' not found” |
| TC03 | 新增商品         | {协议+域名}/products/add | POST   | title="我的测试商品" | 状态码201，返回新增的商品数据                    |
| TC04 | 更新商品         | {协议+域名}/products/1   | PUT    | title="修改后的标题" | 状态码200，title字段已更新                       |
| TC05 | 删除商品         | {协议+域名}/products/1   | DELETE | id=1                 | 状态码200，isDeleted字段为True                   |



## 模块三：购物车接口（/carts）

| 编号 | 测试点                                       | 接口            | 方法   | 输入                                       | 预期结果                                                     |
| ---- | -------------------------------------------- | --------------- | ------ | ------------------------------------------ | ------------------------------------------------------------ |
| TC01 | 查询全部购物车                               | {协议+域名}     | GET    | 无                                         | 状态码200，返回所有商品详情                                  |
| TC02 | 查询单个购物车                               | {协议+域名}/1   | GET    | id=1                                       | 状态码200，返回id=1的购物车详情                              |
| TC03 | 新增一个购物车（商品id存在，quantity为正数） | {协议+域名}/add | POST   | userId=1, products=[{id:1, quantity:2}]    | 状态码201，返回新增的购物车数据，返回值与传入数据一致        |
| TC04 | 新增一个购物车（商品id不存在）               | {协议+域名}/add | POST   | userId=1, products=[{id:9999, quantity:2}] | **实际**：状态码201，但products为空、统计字段全为0；**发现问题**：状态码与实际结果语义不一致 |
| TC05 | 新增一个购物车（quantity=0）                 | {协议+域名}/add | POST   | userId=1, products=[{id:1, quantity:0}]    | **实际**：状态码201，quantity被静默改为1；**发现问题**：输入未经校验被篡改，且无提示 |
| TC06 | 新增一个购物车（quantity为负数）             | {协议+域名}/add | POST   | userId=1, products=[{id:1, quantity:-5}]   | **实际**：状态码201，total计算为负数（-49.95）；**发现问题**：严重，可能导致金额计算错误，存在资损风险 |
| TC07 | 更新购物车                                   | {协议+域名}/1   | PUT    | merge=true, products=[{id:1, quantity:1}]  | 状态码200，新商品追加到原有商品列表中                        |
| TC08 | 删除购物车                                   | {协议+域名}     | DELETE | id=1                                       | 状态码200，isDeleted为true，返回deletedOn时间戳              |



## 缺陷汇总

| 编号  | 问题描述                                      | 复现条件           | 严重程度 |
| ----- | --------------------------------------------- | ------------------ | -------- |
| BUG01 | 商品数量允许负数，总价计算随之变为负数        | quantity=-5        | 高       |
| BUG02 | 商品数量传0会被静默修改为1，无任何提示        | quantity=0         | 中       |
| BUG03 | 添加不存在的商品ID，返回成功（201）但数据为空 | id=99999（不存在） | 中       |
