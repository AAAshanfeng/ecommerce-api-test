# 电商购物流程接口自动化测试

## 项目说明
基于DummyJSON API，设计并实现覆盖登录鉴权、商品管理、购物车管理的
接口自动化测试，包含完整业务流程串联测试与边界值缺陷分析。

## 测试范围
- 登录模块：6条用例（正向+反向，覆盖空值/字段缺失等边界场景）
- 商品模块：CRUD完整覆盖
- 购物车模块：CRUD + 3个边界值缺陷发现
- 完整业务流程：登录→查看商品→加入购物车→验证数据一致性

## 测试中发现的问题
### 问题1：购物车商品数量允许负数，导致总价计算为负

- **复现步骤**：POST /carts/add，products中quantity传-5
- **期望结果**：应返回400错误，提示数量必须为正整数
- **实际结果**：返回201成功，total字段计算为-49.95
- **严重程度**：高（可能导致金额计算错误，存在资损风险）

### 问题2：购物车商品数量传0，被静默修改为1

- **复现步骤**：POST /carts/add，products中quantity传0
- **期望结果**：应保留用户输入的0，或返回校验错误
- **实际结果**：接口自动将quantity改为1，无任何提示
- **严重程度**：中（用户输入与实际存储不符）

### 问题3：添加不存在的商品ID，返回成功但数据为空

- **复现步骤**：POST /carts/add，products中id传99999（不存在的商品）
- **期望结果**：应返回404或400，提示商品不存在
- **实际结果**：返回201成功，但products列表为空
- **严重程度**：中（状态码与实际结果语义不一致）
